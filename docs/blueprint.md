# **App Name**: MediFlow

## Core Features:

- WhatsApp Automation via n8n: Integrate n8n for automating WhatsApp responses to patients.
- Appointment Scheduling via n8n: Automatically schedule appointments in Google Calendar through n8n based on patient responses.
- QR Code Payment System: Collect payments via QR code through the clinical system and verify payments via staff confirmation.
- Integrated Course System: Display course materials and resources within the patient portal. Serve files stored at specified URLs, or links to external sites.
- AI-Powered Follow-ups: Generate personalized, conversational follow-up messages to patients through WhatsApp, via n8n automation, after appointments. The tool may incorporate details from patient records or appointment notes when generating the follow-up message, depending on relevance.
- Training Module and Admin Panel: A module that allows admin to upload online classes, record sessions, and invite users.

## Style Guidelines:

- Primary color: Calm light blue (#89CFF0), evoking a sense of trustworthiness, health, and tranquility, appropriate for a medical setting.
- Background color: Very light blue (#E5F5FF), to complement the primary and create a serene atmosphere.
- Accent color: Soft teal (#77DDE7), an analogous color to the primary, to provide visual interest while remaining calm and professional.
- Body and headline font: 'PT Sans', a humanist sans-serif to bring a modern yet approachable feel.
- Use clean, line-based icons to represent medical services and appointment types. Icons should be easily recognizable and align with the overall calming aesthetic.
- Maintain a clean, spacious layout with a clear visual hierarchy. Use whitespace effectively to avoid overwhelming users with information. The design should be responsive across devices.
- Use subtle animations and transitions to enhance the user experience without being distracting. For example, a gentle fade-in for new content or a smooth transition between pages.
